Rust Univeral Machine

  • Fully functioning, turing complete, virtual machine
  • Optimized to improve performance
  • Runs on 32-bit segmented memory
  • Uses 8 general purpose 32-bit registers
  • Uses a large address space of memory segments
  • Can be programmed with 13 unique instructions and simulate behavior of any other computer.
